**软件名称**：日本語チャット（日语聊天陪练系统）
**软件简称**：日语聊天
**版本号**：V1.6.1
**开发方式**：独立开发
**开发语言**：Python 3.12 / JavaScript（原生 ES6）
**技术架构**：FastAPI 后端 + 原生 Web 前端（PWA），前后端分离

## 一、软件概述

### 1.1 软件简介

日本語チャット（日语聊天陪练系统）是一款面向日语学习者的 AI 语音对话陪练应用。系统内置一名虚拟日语学习伙伴「小樱」（さくら），用户可通过打字或语音与她进行日语对话，系统基于大语言模型生成自然、符合语境的日语回复，并提供发音朗读、实时纠错、生词收集、间隔复习等完整学习闭环，帮助用户在真实对话场景中开口练习日语。

### 1.2 开发目的

传统日语学习 App 以背单词、看语法为主，缺乏「开口说」的训练环节，学习者普遍存在「学了很多、说不出口」的问题。聘请真人外教陪练成本高、时间难以保证。本软件通过 AI 以极低成本复刻「真人外教陪练」体验：

- 随时随地可练：通勤、睡前、出国前碎片时间均可使用；
- 开口就有反馈：每一句话都得到回应，错误立即被纠正；
- 沉浸式场景：35 个真实生活场景角色扮演，学完即用；
- 科学复习：聊天收词 → 遗忘曲线复习 → 测验巩固，形成完整闭环。

### 1.3 适用对象

- 日语零基础至 N1 水平的学习者；
- 口语薄弱、需要开口练习的人群；
- 备考日语能力考试（JLPT）的考生；
- 计划赴日旅游、留学、工作的用户。

## 三、软件功能

### 3.1 AI 日语对话（核心功能）

用户通过文字或语音与虚拟角色「小樱」进行日语对话。系统调用 DeepSeek 大语言模型生成符合语境的日语回复，支持：

- **即时响应**：每句话都有回应，绝不冷场；
- **自然口语**：采用贴近真实日本人的口语表达方式，而非书面语；
- **主动引导**：AI 主动抛出问题，引导用户多开口；
- **多场景角色扮演**：支持 35 个生活场景（餐厅点餐、问路、酒店入住、面试、医院看病等），AI 扮演店员、司机、面试官等角色。

### 3.2 难度分级（N5 ~ N1 五档自适应）

系统内置日语能力考试五档难度体系，用户可随时切换：

| 档位 | 说话特征 |
| --- | --- |
| N5（入门） | 短句为主，必注假名，仅用 N5 词汇 |
| N4 | 中短句，难字注假名 |
| N3 | 中等句长，常用词汇 |
| N2 | 较长句，不注假名，使用敬语谦让语 |
| N1（最高） | 无句长限制，专业话题，商务敬语 |

切换难度后，前端实时显示当前档位小樱的说话特征标签（按档位变色），后端通过 5 套硬性量化指令（句长、词数、注假名规则、句式复杂度）约束 AI 回复风格，确保档位差异可感知。

### 3.3 语音功能

- **语音朗读（TTS）**：AI 回复自动语音朗读，后端优先使用微软 Edge TTS 免费日语语音合成（女声七海 Nanami / 男声圭太 Keita），支持 0.5x ~ 1.5x 五档语速调节；自带 256 条 LRU 缓存，相同文本不重复合成；若 Edge TTS 不可用自动降级 ElevenLabs API 或浏览器内置语音。
- **语音识别（STT）**：通过浏览器 Web Speech API 实现日语语音识别，支持手动按麦说话。
- **免提对话模式**：开启后自动形成「听 → 说 → 听」循环，无需反复点击按钮，接近真实通话体验。
- **朗读打断（Barge-in）**：免提模式下，小樱朗读时用户一开口，系统通过麦克风能量检测（Web Audio API 分析音量 RMS）立即停止朗读并进入聆听状态，实现「随时可以插话」的实时感。
- **流式输出（SSE 打字机）**：AI 回复通过 SSE（Server-Sent Events）流式传输，文字逐字滚动显示，无需等待全文生成，显著缩短等待感。

### 3.4 即时纠错

对话中 AI 发现用户日语错误时当场纠正，给出正确说法和讲解；纠错按类型分类（语法 / 用词 / 搭配 / 助词），并自动记入错题本供复习。

### 3.5 生词自动收集（生词本）

对话中出现的生词由 AI 标注并自动收入生词本（按日分组），附带假名读音与中文释义；支持一键导出为 Anki 可导入的 CSV 文件，可与第三方复习软件衔接。

### 3.6 SRS 间隔复习引擎

采用 SuperMemo SM2 算法简化实现，为每个生词维护间隔天数、难度系数（EF）、复习次数、下次复习日期。到期单词自动提醒复习，用户按掌握程度打分（0-5），系统动态调整复习间隔，实现符合遗忘曲线的科学复习。

### 3.7 辅助学习工具

- **翻译练习**：内置 60+ 道中日互译题库，支持中译日 / 日译中方向，可分级练习；
- **救急短语**：内置 17 条高频应急短语（求助、道歉、确认等），可快速点读；
- **量词专项练习**：日语量词（个、本、枚、匹等）配搭选择题练习；
- **注假名（振假名）**：任意文本用 janome 分词自动标注汉字读音，支持 JSON / HTML 两种输出；
- **查词翻译**：对话中可随时查询单词释义与翻译。

### 3.8 数据记录与统计

- 对话历史按会话保存，支持导出 Markdown 格式；
- 学习统计：打卡天数、对话轮数、生词数量、错题数量；
- 弱项分析：按错误类型统计生成弱项分布报告；
- 场景通关检测：对话满足场景核心要素后自动标记场景达成。

### 3.9 其他特性

- **访问口令保护**：部署公网后可通过口令（Access Code）防止陌生人盗用 API 额度；
- **PWA 支持**：可安装到手机主屏幕，离线缓存静态资源，像原生 App 一样全屏运行；
- **会话隔离**：多端会话独立（X-Session-Id），互不干扰。

## 四、软件操作说明

### 4.1 启动服务

```bash
cd backend
pip install -r ../requirements.txt
python server.py
```

启动后访问 `http://localhost:8765` 即可打开聊天界面。

### 4.2 开始聊天

1. 打开网页进入主界面，小樱会主动打招呼「こんにちは！さくらです🌸」；
2. 在底部输入框输入日语或中文，按回车（或点击 ➤ 按钮）发送；
3. 小樱以日语回复，自动朗读，回复正文下方显示「再听一遍」「注假名」「跟读」「译文」按钮；
4. 点击「生词」徽章可查看本日收集的生词列表。

### 4.3 语音对话

1. 点击底部 🎤 按钮说话（需允许麦克风权限），说完自动发送；
2. 点击「🎧 免提」进入免提模式：小樱朗读结束后自动进入聆听状态，说话即可回复；朗读期间说话可随时打断；
3. 点击「🔇 只听」仅聆听小樱朗读而不触发识别；
4. 通过「语速」下拉可调节朗读速度（0.5x ~ 1.5x）。

### 4.4 切换难度

1. 顶部难度下拉选择 N5 ~ N1；
2. 切换后界面标签即时更新显示当前档位小樱的说话特征；
3. 后续对话中小樱的词汇、句长、注假名风格随之调整。

### 4.5 场景角色扮演

1. 点击顶部「💬 自由聊天」进入场景列表；
2. 选择场景（如「餐厅点餐」），小樱扮演店员开场；
3. 在场景内完成对话，满足核心要素后场景标记达成。

### 4.6 练习与复习

- 「📝 翻译练习」：中译日 / 日译中答题，即时判分；
- 「🔢 量词」：量词选择题练习；
- 「📓 生词」：查看生词、导出 Anki CSV；
- 「🆘 救急短语」：应急场景常用句点读。

## 六、技术特点

1. **流式对话（SSE）**：采用 Server-Sent Events 实现 AI 回复打字机效果，首字延迟显著降低，对话节奏更接近真人；
2. **免提 + 朗读打断（Barge-in）**：通过 Web Audio API 实时分析麦克风输入能量（RMS 阈值检测），朗读中检测到用户开口立即打断进入聆听，实现半双工「实时通话感」；
3. **难度硬性量化**：5 档难度通过句长、词汇量、注假名、句式复杂度等硬性参数约束 AI 输出，档位差异可量化、可感知；
4. **多级 TTS 降级**：Edge TTS → ElevenLabs → 浏览器内置语音三级保障，确保任何环境下都能发声；
5. **完整学习闭环**：对话纠错 → 生词收集 → SM2 间隔复习 → 测验巩固，形成「输入-输出-复习」闭环；
6. **前后端分离 + PWA**：原生 JS 前端（零框架、零构建）跨平台部署，支持手机主屏安装；
7. **会话与数据隔离**：基于 Session ID 的多端数据隔离，支持多用户并行使用；
8. **成本可控**：对话使用 DeepSeek 大模型（价格低廉），语音使用免费 Edge TTS，适合个人开发者长期运营。
