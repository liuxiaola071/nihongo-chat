    • ③ 核心对话链路（POST /api/chat）
      • 前端触发
        • 用户输入 → sendToAI()：isSending 锁防并发 → addMsg('me') 显示气泡 → showTyping 打字机 → POST /api/chat
        • 请求头：X-Access-Code（口令）+ X-Session-Id（会话隔离）
        • 请求体：{text, scenario, mode, level, rate, tone}
      • 后端 7 步处理
        • 0. 认证+会话：_require_auth（ACCESS_CODE 空则跳过；cookie 或头匹配）→ _get_session（头→cookie→uuid 新生成，30天 httponly）
        • 1. 入参校验：空文本 400｜超过 MAX_INPUT_LENGTH=500 字 400
        • 2. AI 调用：chat_with_sakura(text, sid, scenario, mode, level, tone)——按会话隔离历史 + 场景 prompt + 模式/难度/语气指令
        • 2.5 打卡：_record_checkin(sid) 记录今日打卡日期
        • 3. 解析纠错：_parse_fix 用正则提取 ###FIX###...###FIXEND### 块 → FixItem 列表；有纠错自动入错误本 _save_errors
        • 4. 剥标记：_strip_fix 从正文移除纠错块（纠错单独卡片展示，不进语音）
        • 5. 拆生词：split_reply 拆 ###WORDS### 行 → add_words 写生词本 + srs.add_words_batch 进复习系统
        • 6. 语音合成：text_to_speech(正文, rate) → base64
        • 7. 场景检测：check_completion 匹配通关关键词 → scene_done → _record_scene_done 入统计
      • 返回结构
        • ChatResponse：{reply(正文), audio_b64(语音), new_words(生词列表), fix_items(纠错列表), scene_done(通关标志)}
      • 前端渲染
        • addMsg('ai')：按句号/问号/感叹号拆句(可点击点读) → 纠错卡片 ❌→✅+note → 生词 chips → 场景完成 🎉 徽章
        • 自动播放语音（非只听模式）→ 免提模式 600ms 后自动重新开听（闭环）
        • 生词自动保存到本地 localStorage 双备份 + 顶部 badge 计数更新
      • 容错设计
        • AI 超时(45s)/网络失败/返回异常 → 日语兜底话术（不报错不中断）
        • AI 失败不写入历史（不污染记忆）｜历史超 10 轮(20条)丢弃最老 2 条
        • 生词/纠错标记解析失败不影响正文展示
    • ④ 四大对话模式
      • chat 自由聊天（默认）
        • system = 人格 + 场景 prompt + 级别指令 + 语气指令 + VOCAB_INSTRUCTION
        • AI 输出：正文 + 可选 ###WORDS### 生词行
      • correct 纠错模式
        • system 追加 FIX_INSTRUCTION：输出 ###FIX### ❌→✅（解释）###FIXEND###，可多条，无错写「なし」
        • 后端解析成 FixItem → 前端 correction-bar 纠错条 + 气泡内 fix-card
        • 纠错自动进错误本（改进点② 的数据来源）
      • translate 翻译模式
        • TRANS_MODE_INSTRUCTION 压过一切：跳过级别/语气/生词指令
        • 无状态：不带历史上下文（否则 AI 会继续对话而非翻译）
        • 自动判定中↔日，其他语言双语翻译；不收集生词、不入历史
      • word 查词模式
        • WORD_MODE_INSTRUCTION：固定格式 📖意思/🔊读音/📝例句/💬用法/類義語
        • 不收集生词（模式内已经查了）
        • 前端触发：划选日语文字(≤15字) → 400ms 定时 → word-popup 弹窗展示
      • 模式切换实现
        • 前端 mode-bar 4 个 mode-chip → switchMode(modeId) 更新输入框 placeholder → 提交带 mode 参数
        • 模式卡片带 CSS 类（mode-chat/correct/translate/word）区分气泡样式

    • ⑥ 生词本系统
      • 自动收集链路
        • AI 回复带 ###WORDS### 行 → 格式「単語|ひらがな|中国語の意味;」（分号/换行分隔，1-4 词，无则「なし」）

        • 前端同时 saveVocab 写入 localStorage nihongo_vocab 双备份（防服务器数据丢失）
      • 解析过滤规则
        • 跳过「なし/無し/none/-」等占位符｜>30 字符的词丢弃
        • 支持 ；； 、换行 、|｜ 多种分隔符
      • 存储结构
        • vocab.json：{sid: {日期: [{word, kana, meaning}]}}
        • 按 word 去重（同日重复词不叠加）｜单日上限 MAX_WORDS_PER_DAY=300
        • 写盘：tmp 文件 + os.replace 原子替换（防写一半损坏）

        • DELETE /api/vocab?day= → 清空某天生词（confirm 确认）
        • GET /api/vocab/export → Anki CSV：正面「単語（かな）」背面中文｜CSV 转义("→"") + 服务端 ﻿ BOM（Excel 不乱码）

        • header 📓 生词按钮 + badge 今日新词计数（角标）
        • vocab-sheet：日期 tab 切换历史生词 / 导出 Anki / 清空按钮

    • ⑦ SRS 间隔复习（SM2 算法）⚠️无UI
      • 数据流
        • 聊天生词自动进 SRS（srs.add_words_batch）→ 无需手动添加
        • 按 next_review 日期到期 → 学习者复习打分 → 更新间隔
      • SM2 算法参数
        • quality 0-5：5秒答/4犹豫/3困难/2错但见过/1忘/0不会
        • 间隔：首次成功 1天 → 二次 6天 → 之后 round(interval × ef)
        • quality<3：重置 interval=1, reps=0（重新爬坡）
        • ef(难易因子)：ef + (0.1 - (5-q) × (0.08 + (5-q) × 0.02))，下限 1.3
      • 卡字段
        • word/kana/meaning/interval/ease_factor/repetitions/next_review/last_review/total_reviews/created
        • srs.json：{sid: {word: 卡数据}}
      • 到期查询
        • get_due_words：next_review ≤ 今天，按 interval 升序（先复习间隔短的）
        • mastered 掌握：reps≥3 且 interval≥21天（算长期记忆）
      • API（已实现）
        • GET /api/srs/due → {words, stats}｜POST /api/srs/grade {word, quality} → 更新卡
        • GET /api/srs/stats → 复习统计
      • ⚠️ 已知缺口（改进点③ 最高优先）
        • 算法完整 + API 就绪，但前端没有任何复习界面！
        • 建议：做 srs-sheet 复习卡片弹层（正面单词 → 回忆 → 打分 0-5 → 下一张）
        • 与改进点②错误本复习一起做，完成『聊天收词→复习→测验』闭环
    • ⑧ 错误本与弱项分析 ⚠️无UI
      • 数据来源
        • correct 纠错模式（或 AI 主动纠错）→ 后端 _save_errors(sid, fix_items)
        • 去重键：(wrong, correct) 组合，重复只保留最新，自动补 date=今天
      • 存储结构
        • errors.json：{sid: [{wrong, correct, note, date, scenario}]}
      • 弱项分析 _get_weakness
        • 5 分类：助詞 / 時制・活用 / 敬語 / 語彙・表現 / その他
        • 分类规则：优先 note 关键词匹配（中日英关键词表）→ 回退 correct 特征启发式
        • 特征：含 ました/ています → 時制｜ください/いただく → 敬語｜correct 长度≤4 → 助詞｜否则 語彙・表現
        • 返回：{total_errors, categories:[{name,count}], recent: 最近10条倒序}
      • API
        • GET /api/stats → 含 weakness 字段｜GET /api/stats/weakness → 单独弱项分析
      • ⚠️ 已知缺口（改进点②）
        • 后端已存 + 弱项分析已算，但前端无查看/复习界面（半成品）
        • 建议：升级为『错题复习』入口 —— 与 SRS(③) 一起做，说明书多 2 章

      • 题库
        • TRANSLATION_PAIRS 约 60 题，diff=1~5 对应 N5~N1（双向：中→日 / 日→中）

      • 接口
        • GET /api/assist/quiz?direction=j2c|c2j|random&count=&difficulty=

        • header 📝 翻译练习按钮 → quiz-sheet 弹层

        • QUIZ_TOTAL=10：loadQuiz 请求 20 题 → 前端 shuffle 抽 10 题
        • 判分：checkQuizAnswer 归一化比较（忽略空格）→ 1.4s 自动下一题
        • 结果分级：≥90% 🏆 / ≥70% 😊 / ≥50% 🤔 / <50% 📚
      • ⚠️ 已知缺口（改进点⑤）
        • 题库约 60 题偏少，且 N1 方向题较少，建议扩充到 200+ 并加更多中→日题

    • ⑬ 跟读评分（影子跟读）
      • 入口
        • AI 消息气泡上的 🗣️ 跟读按钮（每条 AI 回复都有）
      • 流程
        • initScoreSpeech：SpeechRecognition，lang=ja-JP，maxAlternatives=3（多候选取最优）
        • startShadowing：示范朗读 2 次 → 3 秒倒计时 → 录音 → 识别 → 评分
      • 评分公式
        • comparePronunciation：编辑距离相似度 × 70% + 识别置信度 × 30% = 综合分
        • 结果分级：≥90 😎完美 / ≥75 😊很棒 / ≥55 🤔还行 / <55 😅再练练
      • 结果展示
        • showShadowResult 卡片：示范原文 / 你的发音识别结果 / 候选词列表
        • 按钮：重试 / 关闭

    • ⑲ 数据存储（backend/data/ 5 个 JSON）
      • chat_history.json（对话历史）
        • 结构：{histories: {sid: [{role, content}]}, last_active: {sid: ts}}
        • 上限：MAX_SESSIONS=200 会话｜SESSION_TTL=86400（24h 无活动清理）｜每会话 MAX_HISTORY_TURNS=10 轮(20条)

      • vocab.json（生词本）
        • 结构：{sid: {日期: [{word, kana, meaning}]}}｜单日 300 上限｜按 word 去重
      • srs.json（复习卡）
        • 结构：{sid: {word: {kana, meaning, interval, ease_factor, repetitions, next_review, last_review, total_reviews, created}}}
      • stats.json（统计）
        • 结构：{sid: {checkins: [日期], scenes_done: {场景id: 日期}, last_active: ts}}
      • errors.json（错误本）
        • 结构：{sid: [{wrong, correct, note, date, scenario}]}｜按 (wrong, correct) 去重
      • 通用写盘规范
        • 全部采用：tmp 临时文件写入 → os.replace 原子替换（防崩溃损坏）
        • 全部采用：3 秒防抖合并写入（省 IO）｜线程锁保护共享状态
