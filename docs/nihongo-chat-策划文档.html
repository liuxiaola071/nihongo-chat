  • 日本語チャット（跟小樱聊天）策划设计文档 v1.6
    • ① 产品定位与设计理念
      • 一句话定位
        • 日语口语陪练 App：和虚拟角色「小樱」聊天，开口练日语
        • 本质：把『真人外教陪练』用 AI 低成本复刻，随时随地可练
      • 目标用户
        • 日语零基础 ~ N1 学习者，口语是最大短板的一批人
        • 想练但没条件：没钱请陪练 / 没时间上课 / 不敢开口
        • 使用场景：通勤碎片时间、睡前 10 分钟、出国前突击
      • 核心卖点（三大支柱）
        • ① 真实场景沉浸：35 个生活场景角色扮演，学完就能用
        • ② 即时纠错反馈：说错立刻纠正+讲解，开口就有收获
        • ③ 科学复习闭环：聊天收词 → 遗忘曲线复习 → 测验巩固
        • ✅ 补充说明：已通过 barge-in（朗读可被打断）+ SSE 流式（回复打字机逐字出现）逼近『实时通话感』——免提模式下小樱朗读时你一开口，朗读立刻停下进入聆听（见⑯）
      • 设计理念
        • 传统 App 只教不练，本产品把『练』放核心：一切学习素材都从对话中产生
        • 游戏化类比：对话=打怪刷经验，纠错=战斗反馈，生词=战利品，复习=回家练功
        • 零门槛：打开就能聊，不需要先学语法再来
      • 软著背景
        • 个人独立开发项目，唯一开发人，用于软件著作权登记
    • ② 核心玩法循环（学习闭环）
      • 玩法闭环（主循环）
        • ① 进场景：选一个生活场景（餐厅/问路/面试…）
        • ② 开口对话：和小樱用日语交流，说错不尴尬
        • ③ 即时纠错：小樱纠正错误并讲解，错误自动记入错题本
        • ④ 生词入账：对话中新词自动收进生词本
        • ⑤ 回家复习：错题本+生词本按遗忘曲线提醒复习
        • ⑥ 测验巩固：翻译/量词/跟读专项练习验证成果
      • 设计目标
        • 每次打开都有明确目标，玩 10 分钟也有获得感
        • 闭环自带驱动力：聊得越多 → 素材越多 → 复习越有针对性
      • 驱动力设计
        • 即时反馈：每一句话都有回应，错误立刻被纠正（正反馈快）
        • 成长可见：打卡天数/场景通关/生词数量都有记录
        • 目标感：35 个场景像 35 个关卡，通关有成就感
    • ③ 角色「小樱」设计
      • 人设
        • 设定：温柔耐心的日语学习小伙伴，像邻家学姐
        • 性格：鼓励式教学，说错了也是『没关系，这样说是对的』
        • 语气：自然口语，贴近真实日本人说话方式（不用书面语）
      • 难度自适应
        • 对话难度随用户水平自动调节：零基础用简单词，高手自动上难度
        • 难度档位：N5（入门）→ N4 → N3 → N2 → N1
        • 现状：前端有难度选择器，切换后通过接口传给 AI（5 套难度指令已接入对话链路）
        • ✅ 已强化：后端 5 档硬性量化指令（句长/词数/假名注音/句式复杂度逐档递增，N5 短句必注假名，N1 自由复杂表达）+ 前端实时提示标签（#level-hint 按难度变色显示当前档说话特征）
      • 对话规则（AI 行为准则）
        • 有问必答：每句话都给回应，绝不冷场
        • 即时纠错：发现明显语法/用词错误，当场纠正+给正确说法
        • 引导话题：主动抛问题引导用户多开口
        • 教学辅助：用户主动问词/问翻译时，即时解答
    • ④ 场景系统（核心玩法·35 场景）
      • 场景是什么
        • 模拟真实生活场景的角色扮演对话——小樱扮演店员/司机/医生等
        • 每个场景解决一个真实生活需求，学完即用
      • 场景一览（6 大分类 35 个）
        • 社交类（6 个）
          • 打招呼 / 约人 / 聊爱好 / 介绍家人 / 委婉拒绝 / 打电话
        • 购物类（7 个）
          • 找超市 / 收银结账 / 逛街 / 洗衣店 / 便利店 / 维修店 / 银行
        • 出行类（7 个）
          • 打车 / 坐公交 / 问路 / 酒店入住 / 景点咨询 / 机场 / 餐厅点餐
        • 职场类（10 个）
          • 面试 / 入职第一天 / 汇报工作 / 技术讨论 / 处理办公问题 / 请假 / 着装要求 / 申请升职 / 辞职 / 职场日常
        • 学习类（2 个）
          • 考试咨询 / 网课交流
        • 应急类（2 个）
          • 紧急呼叫 / 医院看病
        • 自由聊天（1 个）
          • 无场景限制，想聊什么聊什么
      • 场景难度分级（由易到难）
        • 入门：打招呼 / 便利店 / 问路 —— 高频短句
        • 进阶：餐厅 / 酒店 / 购物 —— 多轮交流
        • 高阶：面试 / 升职 / 技术讨论 —— 复杂表达+敬语
      • 场景通关设计
        • 通关条件：在对话中说出指定关键表达即算通关（目前 8 个场景开放）
        • 已开放通关场景：餐厅 / 酒店 / 购物 / 打招呼 / 问路 / 医院 / 面试 / 打车
        • 通关反馈：记录通关状态，作为成长足迹
        • 设计目的：给用户『这关过了』的清晰小目标，像游戏打关
      • 设计价值
        • 消除『学了一堆用不上』的挫败感——每个场景都是真实刚需
        • 角色扮演降低开口羞耻感——对面是 AI，错了也没关系
    • ⑤ 对话模式（4 种玩法）
      • 模式一：自由聊天
        • 玩法：不设场景，想聊什么聊什么（天气/爱好/今日见闻）
        • 适用：日常热身、碎片时间随口练
        • 反馈：同样有纠错+生词收集
      • 模式二：场景扮演
        • 玩法：选择场景进入角色，小樱扮演对方角色，完成任务式对话
        • 适用：针对性练习（马上要去日本旅游 → 练餐厅/问路）
        • 反馈：通关判定+纠错+生词
      • 模式三：翻译助手
        • 玩法：直接发中文要翻译 / 发日语问意思，支持语音输入
        • 适用：查词查句、写东西时的即时翻译
        • 反馈：中↔日双向翻译
      • 模式四：跟读练习
        • 玩法：听小樱说一句 → 用户跟读 → 系统给发音评分
        • 适用：纠正发音、练习语调（影子跟读法）
        • 反馈：评分结果即时反馈
      • 模式切换
        • 聊天窗口内一键切换，无需退出重进
    • ⑥ 纠错系统（即时反馈核心）
      • 纠错时机
        • 对话中自动检测明显语法错误 / 用词不当
        • 不打断对话：小樱先回应内容，再自然给出纠正
      • 纠错反馈形式
        • 聊天内嵌显示：指出错误 → 给正确说法 → 简短讲解为什么
        • 示例：『わたしは 学生 です』中『私→わたし』等假名/汉字问题也会提示
      • 错误自动入账
        • 每次纠正自动记入『错误本』（自动去重，同错不重复记）
        • 错误本成为专属复习素材：我犯过的错，重点练
      • 弱项分析
        • 错误自动归类 5 类弱项：助词 / 时态活用 / 敬语 / 词汇表达 / 其他
        • 形成个人弱项画像：一眼看透『我的日语弱在哪』
        • 示例：连续错『は/が』→ 判定助词弱项
      • 设计价值
        • 把『犯错』变成学习资源——每次犯错都是精准的复习素材
    • ⑦ 生词本系统（战利品收集）
      • 收词规则
        • 对话中自动提取生词，无需手动添加
        • 记录词条信息：写法 / 假名注音 / 中文释义 / 原句语境
      • 查看与学习
        • 生词列表：按时间 / 难度浏览，可筛选
        • 点词即听发音（语音播放）
        • 点击查看例句：词不离句，句不离境
      • 与复习联动
        • 生词自动进入 SRS 复习队列，按遗忘曲线安排复习
        • 设计目的：聊天收的词，系统负责帮你记牢
      • 导出功能
        • 一键导出 Anki 卡组：想在外部工具复习也可以
      • 设计价值
        • 零操作成本收词——不用停下来记笔记，专注对话本身
    • ⑧ 复习系统（SRS 间隔复习）
      • 设计原理
        • 人类记忆符合『遗忘曲线』：不复习 → 很快忘；在快忘时复习 → 记得牢
        • 系统自动安排每张卡片的复习时间，到期提醒
      • 复习流程
        • 看卡片（生词/错题）→ 先回忆 → 看答案 → 自评记住程度
      • 核心数值规则（SM2 算法）
        • 评分制：0~5 分（0=完全忘了，5=轻松答对）
        • 首次复习：1 天后
        • 第二次：6 天后
        • 之后：按上次评分调整间隔（评分越高间隔越长）
        • 掌握标准：连续 3 次答对且间隔超过 21 天 = 掌握
        • 遗忘惩罚：评分低于 3 分 → 重置复习节奏，重新练
      • ⚠️ 现状与规划
        • 后端复习引擎已就绪（规则已实现，可自动排期）
        • 前端『复习入口』未开放——用户目前无法主动进入复习
        • 完善优先级：⭐最高——打通『聊天→收词→复习→测验』闭环的关键一环
    • ⑨ 错误本与弱项分析
      • 记录规则
        • 对话中所有纠错自动归档（按错误+正确说法去重）
        • 记录信息：错误句子 / 正确说法 / 讲解 / 出错日期 / 所在场景
      • 弱项分类（5 类）
        • 助词（は/が/を/に 等用错）
        • 时态·活用（て形/ない形/过去式等）
        • 敬语（です/ます 与 谦敬语混用）
        • 词汇·表达（用词不当/直译中式）
        • 其他（语序/助数词等）
      • 玩家价值
        • 『错题复习』入口（规划中）：像刷错题本一样反复练自己的错
        • 弱项分布一目了然：优先补哪块，心里有数
      • ⚠️ 现状与规划
        • 记录+弱项分析后端已就绪
        • 前端『错题复习』入口待开发（与 SRS 复习一起做）
        • 完善优先级：⭐最高（与⑧并列）
    • ⑩ 成长与激励体系
      • 每日打卡
        • 打开 App 即打卡，连续天数自动累计
        • 设计目的：养成每日开口的习惯（语言学习贵在坚持）
      • 场景通关记录
        • 每个场景的通关状态留痕，可回看自己打过的关卡
      • 学习统计
        • 对话次数 / 对话时长 / 生词总数 / 错误总数 / 复习次数
        • 让进步肉眼可见（数据是最好的激励）
      • 成就徽章（规划中）
        • 连续打卡 7 天 → 徽章『全勤小樱』
        • 通关全部场景 → 徽章『场景征服者』
        • 集齐 N5 生词 → 徽章『词库初成』
        • 设计目的：给里程碑时刻仪式感，防止中途放弃
    • ⑪ 专项练习模块
      • 翻译练习
        • 题库：约 60 题，中↔日双向（中译日 / 日译中）
        • 难度：N5~N1 五档，按用户水平出题
        • 形式：每轮 10 题，做完出成绩
        • 规划：题库扩充到 200+，覆盖高频考点
      • 量词专项
        • 玩法：练习日语量词（个/本/张/台/只/册/人/杯）
        • 重点：量词音变规则（1 本=いっぽん、3 本=さんぼん 等）
        • 形式：选择/拼写题，即时判对错
        • 设计价值：量词是中文母语者最容易错的高频考点
      • 救急短语
        • 内容：17 句救命日语，5 大类
        • 迷路（3 句）/ 身体不适（3 句）/ 求助（3 句）/ 基础礼貌（5 句）/ 数字（3 句）
        • 特点：一键直达，离线可用——真遇到急事打不开网络也能用
        • 规划：扩充到 50+，增加购物/问路等高频救急
      • 设计价值
        • 碎片时间也能练：通勤 5 分钟刷一轮翻译/量词
    • ⑫ 语音体验设计（开口是关键）
      • 发音播放
        • 所有日语内容均可发音（句子/生词/短语）
        • 四级兜底：高质量 TTS → 备选引擎 → 系统语音 → 浏览器朗读
        • 设计目的：任何设备任何环境都能听到正确发音
      • 语音输入
        • 直接说日语代替打字（浏览器语音识别）
        • 设计目的：打字打断口语节奏，说话才像真对话
      • 跟读评分
        • 影子跟读：听一句 → 读一句 → 系统评分
        • 反馈：发音准确度即时反馈，练语调练节奏
      • 体验细节
        • 常用音频本地缓存：重复播放不卡顿、省流量
    • ⑬ 存档与账号
      • 存档内容
        • 对话记录 / 生词本 / 复习进度 / 错误本 / 打卡统计
        • 存档方式：本地存储（换设备不迁移）
      • 当前形态
        • 单机存档：数据保存在本机，隐私安全
      • 规划
        • 云端同步（可选）：换手机/换电脑不丢进度
        • 账号系统（可选）：多设备共用进度
    • ⑭ 界面与交互设计
      • 主界面
        • 以聊天为主界面：打开就是对话，像打开微信
        • 功能入口清晰：场景选择 / 专项练习 / 复习 / 统计 都在顶部或侧栏
      • 交互反馈
        • 语音播放按钮：点击即听
        • 纠错提示：在聊天流中自然展示，不打断阅读
        • 输入状态：录音/识别中有明确状态提示
      • 视觉风格
        • 深色主题，沉浸式聊天体验
        • 卡片式布局：生词卡/复习卡/练习卡统一风格
    • ⑮ 内容规划与版本路线
      • 内容扩充计划
        • 翻译题库：60 → 200+（覆盖 N5~N1 高频考点）
        • 场景：35 → 50+（增加旅行/就医/商务细分场景）
        • 救急短语：17 → 50+
      • 版本路线图
        • v1.6（当前）：核心对话+场景+生词+练习，闭环后半段未打通
        • v1.6.1（已完成）：难度分级强化（5 档硬性量化+前端提示标签）+ 语音体验升级（SSE 流式打字机 + barge-in 朗读打断）——向『实时通话』迈出两大步
        • v1.7（规划）：SRS 复习入口 + 错题复习入口 —— 打通学习闭环 ⭐
        • v1.8（规划）：成就徽章 + 学习报告 —— 强化激励
        • v1.9（规划）：云端同步 + 账号 —— 数据可搬家
        • v2.0（愿景）：语音通话式实时对话 + 难度感知强化 —— 把『开口说』做到极致
      • 运营想法（长期）
        • 每日一句/每日场景推送：养成打开习惯
        • 主题周活动（旅行周/面试周）：集中攻一个方向
    • ⑯ 已知体验缺口与完善路线
      • 缺口①：学了没处练（最高优先）
        • 问题：生词/错题一直在收，但用户没有『复习』入口
        • 影响：聊完就忘，闭环断在最后一步
        • 方案：做 SRS 复习 UI（看卡→回忆→自评），收词的动力才能真正兑现
      • 缺口②：错了没处看（最高优先）
        • 问题：纠错只出现在对话中，过后找不到；弱项分析无展示界面
        • 影响：错误本形同虚设，弱项画像看不见
        • 方案：错题复习入口 + 弱项分布展示页
      • 缺口③：缺成就感
        • 问题：没有徽章/等级，坚持 7 天和坚持 1 天没有区别
        • 方案：成就徽章体系 + 学习周报
      • 缺口④：收词不能随时听
        • 问题：生词本展示/点读体验待完善
        • 方案：生词卡交互优化（点读/例句/发音强化）
      • 缺口⑤：内容量偏少
        • 问题：翻译 60 题、救急 17 句，练完就没了
        • 方案：按优先级扩充题库
      • 缺口⑥：数据不搬家
        • 问题：单机存档，换设备进度丢失
        • 方案：云端同步（低优先）
      • 缺口⑦：语音不是实时通话（核心体验升级）
